# Headroom brand pack

**Take the next job. Keep room for payday.**

Headroom is the space between opportunity and overextension: cash, time and evidence to take the next job with confidence. The name connects the owner's growth ambition to the reserve the product protects.

The images were generated with the built-in imagegen tool and inspected before use. The app's tiny SVG mark is a simplified native interpretation of the same stepped `h` concept. The artwork is a visual metaphor; product screenshots and measured charts remain separate evidence.

## Visual direction

The mint path rises through an emerald opening while a coral alternative falls below the threshold. This expresses the product's central action: change a payment plan to create room for the next job. The empty space above the path is deliberate. Use one strong path and generous space, rather than a field of dashboard decorations.

| Role | Color |
| --- | --- |
| Ink / identity | `#103E34` |
| Mint / supported path | `#BDE8C4` |
| Ivory / working surface | `#F4F1E9` |
| Coral / shortfall | `#D77862` |

Use Manrope for display and IBM Plex for operational details, consistent with the existing app. The project name is **Headroom** in prose and **headroom.** in the wordmark. Keep the two-line tagline intact when space permits.
